This program crashes because it results in infinite recursion. Here's what happens: login() is called. login() calls validate(). validate() calls login(). login() again calls validate(). This process continues forever. Each function call creates a new Function Execution Context, which is pushed onto the Call Stack. Since neither function ever reaches a base condition or returns, the Call Stack keeps growing until it reaches its maximum size. Finally, JavaScript throws: RangeError: Maximum call stack size exceeded * How would you fix it? function login() { validate(); } function validate() { console.log("Validated"); } login(); --- ## Question 14 Trace the stack. ```javascript function x() { y(); } function y() { z(); } function z() { console.log("Done"); } console.log("Start"); x(); console.log("Finish"); ``` Explain every push and pop.
