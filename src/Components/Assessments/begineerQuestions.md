This is actually a very good approach.

Instead of immediately learning more topics, you're going to **prove that you can apply what you've already learned**:

```text
Variables
Data Types
Operators
Conditionals
Loops
Functions
Function Expressions
Arrow Functions
Callbacks
Arrays
Objects
```

When you solve problems and explain your reasoning, you'll discover:

* What you truly understand
* What you only recognize from notes
* Which concepts need reinforcement before React

---

# Rules

For each problem:

### Give

```text
1. Solution
2. Explanation
3. Output (if asked)
4. Time Complexity (if you know it)
```

Don't worry if you don't know complexity yet.
